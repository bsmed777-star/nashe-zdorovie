В основное приложение
← Главная

1. Выбрать учебный документ

PDF с обычным текстом читаем как текст. Для фото и сканов запускаем распознавание букв прямо в браузере (может занять несколько минут). Это не облачный ИИ: пока не требуется платный ключ, но точность ограничена.

2. Проверить распознанное

Проверь каждый показатель по оригиналу. При ошибке исправь название, значение или единицу; ненужную строку исключи.

3. Архив учебных документов

Оригиналы доступны из закрытого хранилища. После сохранения результаты появятся в разделе «Анализы» основного приложения.

Данные распознаются локально в браузере при помощи PDF.js и Tesseract.js. Для загрузки библиотек нужен интернет. Извлечённый текст не передаётся отдельному ИИ-сервису. Исходный документ и подтверждённые показатели сохраняются в Supabase при нажатии «Сохранить».
